O HTML é a base de toda página web. Sem ele, não existe conteúdo para ser exibido no navegador. Durante o curso, entendi a importância de usar tags semânticas, ou seja, tags que descrevem claramente o que aquele elemento representa, o que ajuda na organização do código e na acessibilidade da página.
🎨 CSS O CSS (Cascading Style Sheets) é a linguagem responsável pela aparência visual das páginas web. Enquanto o HTML estrutura o conteúdo, o CSS define cores, fontes, tamanhos, espaçamentos, posicionamentos e animações.
Com o CSS, aprendi a estilizar páginas de forma organizada, separando o conteúdo da apresentação. Estudei seletores, classes, IDs, pseudo-classes e variáveis CSS. Também aprendi a criar layouts modernos usando Flexbox e CSS Grid, que facilitam muito a organização dos elementos na tela. Um dos pontos mais importantes foi o design responsivo, que faz com que o site se adapte a diferentes tamanhos de tela, como celulares, tablets e computadores, usando media queries.
Além disso, estudei animações e transições, que deixam a página mais bonita e interativa, e também aprendi a organizar o código em arquivos separados, mantendo tudo mais limpo e fácil de manter.
⚙️ JavaScript O JavaScript é uma linguagem de programação que roda diretamente no navegador e é responsável pela interatividade das páginas web. Com ele, uma página deixa de ser estática e passa a reagir às ações do usuário.
Durante o curso, aprendi a manipular o DOM (Document Object Model), que é a forma como o JavaScript acessa e altera os elementos HTML em tempo real. Com isso, consegui criar botões que mudam o conteúdo da página, menus que abrem e fecham, formulários que validam dados, entre várias outras funcionalidades.
Também estudei eventos, como cliques, envios de formulário e rolagem da página. Aprendi a usar funções, arrays, objetos, condições e laços de repetição. Vi também recursos modernos da linguagem, como arrow functions e template literals, que deixam o código mais curto e legível.
Outro ponto importante foi o uso do localStorage, que permite salvar informações no navegador do usuário, e o consumo de APIs com o comando fetch, que permite buscar dados de servidores externos e exibir na página.
☕ Java O Java é uma linguagem de programação orientada a objetos, muito utilizada no mercado, principalmente em sistemas corporativos, aplicativos Android e servidores back-end.
Com o Java, aprendi os conceitos fundamentais da Programação Orientada a Objetos (POO), que são: classes, objetos, atributos e métodos. Entendi que uma classe é como um molde, e um objeto é uma instância desse molde.
Estudei também os quatro pilares da POO: abstração, encapsulamento, herança e polimorfismo. Esses conceitos ajudam a criar códigos mais organizados, reutilizáveis e fáceis de manter.
Aprendi a trabalhar com coleções, como List, ArrayList e Map, que servem para armazenar vários dados de forma organizada. Também estudei o tratamento de exceções com try/catch, que evita que o programa quebre quando ocorre um erro.
Por fim, vi como conectar o Java a um banco de dados usando JDBC, permitindo que o programa salve, leia, atualize e apague informações de forma permanente.
🖥️ Back-End O Back-End é a parte do desenvolvimento que fica "por trás" do site — tudo o que o usuário não vê, mas que faz o sistema funcionar. É onde ficam as regras de negócio, o processamento de dados e a comunicação com o banco de dados.
Durante o curso, aprendi o conceito de API REST, que é uma forma padronizada de comunicação entre o front-end e o back-end. Estudei os principais métodos HTTP:
GET — buscar informações
POST — criar novos dados
PUT — atualizar dados existentes
DELETE — apagar dados
Aprendi a criar um servidor usando Node.js com o framework Express, que permite criar rotas e responder requisições de forma simples e rápida. Também vi como trabalhar com dados no formato JSON, que é o padrão mais usado para troca de informações entre sistemas.
Além disso, estudei a integração com banco de dados relacionais, como MySQL e PostgreSQL, aprendendo a criar tabelas, inserir dados e fazer consultas usando a linguagem SQL.
🐙 Git e GitHub O Git é um sistema de controle de versão, ou seja, uma ferramenta que registra todas as alterações feitas em um projeto ao longo do tempo. Ele permite voltar versões anteriores, trabalhar em equipe sem sobrescrever o código dos outros e manter um histórico completo do desenvolvimento.
Com o Git, aprendi os comandos principais, como:
git init — iniciar um repositório
git add — adicionar arquivos para salvar
git commit — registrar uma alteração
git push — enviar o código para o servidor
git pull — baixar alterações do servidor
O GitHub é uma plataforma online onde é possível armazenar projetos Git e compartilhá-los com o mundo. Aprendi a criar repositórios, fazer branches (ramificações para desenvolver funcionalidades separadas), abrir pull requests e colaborar em projetos em grupo.
Também aprendi a usar o GitHub Pages, que permite publicar sites gratuitamente direto do repositório, o que é ótimo para mostrar projetos no portfólio.
🧠 Considerações Finais Ao longo do 3º ano do curso técnico, tive contato com as principais tecnologias usadas no desenvolvimento web moderno. Comecei pelo HTML, que estrutura o conteúdo, depois o CSS, que dá estilo, e o JavaScript, que traz interatividade. Em paralelo, estudei Java e os conceitos de Back-End, entendendo como funcionam os sistemas por trás das aplicações. Por fim, aprendi a usar Git e GitHub, ferramentas essenciais para qualquer desenvolvedor.
Esse conjunto de conhecimentos me preparou para dar os primeiros passos no mercado de tecnologia, seja como estagiário, freelancer ou desenvolvedor júnior. E o mais importante: aprendi a aprender, pois na programação estamos sempre estudando e evoluindo. 🚀 O Python é uma das linguagens de programação mais populares do mundo, conhecida por sua sintaxe simples e de fácil leitura. É uma linguagem versátil, usada em diversas áreas como desenvolvimento web, automação, análise de dados, inteligência artificial e criação de scripts. Com o Python, aprendi a criar variáveis, funções, condições e laços de repetição de forma muito mais simples do que em outras linguagens. Sua estrutura limpa e organizada permite que o programador foque mais na lógica do que na sintaxe. Estudei também a criação de listas, dicionários e tuplas, que são estruturas de dados essenciais para armazenar e manipular informações. Aprendi a usar bibliotecas como math, random e datetime, que ampliam as funcionalidades da linguagem. No contexto de desenvolvimento web, vi como o Python pode ser usado com frameworks como Flask e Django para criar aplicações back-end completas. Também entendi que ele é muito usado em automação de tarefas repetitivas, como renomear arquivos, enviar e-mails ou coletar dados da internet. Por ser uma linguagem muito amigável para iniciantes e, ao mesmo tempo, poderosa para profissionais, o Python se tornou uma das minhas principais ferramentas de estudo e prática. 🐘 PHP O PHP (Hypertext Preprocessor) é uma linguagem de programação voltada principalmente para o desenvolvimento web no lado do servidor (back-end). Ele é usado para criar páginas dinâmicas, ou seja, páginas que mudam de acordo com as ações do usuário ou com os dados de um banco de dados. Com o PHP, aprendi a criar scripts que rodam no servidor e enviam respostas em HTML para o navegador. Entendi como funciona o processamento de formulários, o envio de dados via métodos GET e POST, e o gerenciamento de sessões e cookies. Estudei também a integração do PHP com banco de dados MySQL, aprendendo a conectar, inserir, consultar, atualizar e deletar informações usando comandos SQL. Isso permite criar sistemas completos, como cadastros de usuários, blogs e lojas virtuais. Aprendi a usar estruturas como if, else, for, while e foreach, além de funções personalizadas e arrays. Também vi como incluir arquivos externos com include e require, o que ajuda a reaproveitar código. O PHP é uma linguagem muito usada no mercado, principalmente em sistemas como WordPress, que move grande parte dos sites do mundo. Aprender PHP me ajudou a entender melhor como funciona o back-end de uma aplicação web. 🎨 Figma O Figma é uma ferramenta de design de interfaces e prototipagem, muito usada por designers e desenvolvedores para criar layouts de sites, aplicativos e sistemas antes de começar a programar. Com o Figma, aprendi a criar telas de forma visual, arrastando e organizando elementos como botões, textos, imagens e ícones. É uma ferramenta que roda direto no navegador, permitindo trabalhar em equipe em tempo real, como se fosse o "Google Docs do design". Aprendi a usar recursos como frames (quadros), componentes reutilizáveis, estilos de texto e cores, além de criar protótipos interativos que simulam a navegação de um aplicativo ou site. Uma das maiores vantagens do Figma é que ele permite planejar a interface antes de escrever qualquer linha de código. Isso economiza tempo e evita retrabalho, pois o desenvolvedor já sabe exatamente como o projeto deve ficar. Também aprendi a exportar elementos, medir espaçamentos e pegar as cores exatas para usar no CSS. Isso faz do Figma uma ferramenta essencial para quem trabalha com desenvolvimento front-end. ⚡ Supabase O Supabase é uma plataforma de back-end que oferece serviços prontos para desenvolvedores, como banco de dados, autenticação, armazenamento de arquivos e APIs automáticas. Ele é considerado uma alternativa open source ao Firebase. Com o Supabase, aprendi a criar um banco de dados PostgreSQL sem precisar configurar um servidor do zero. A plataforma gera automaticamente uma API REST para o banco, o que facilita muito a integração com o front-end. Estudei também o sistema de autenticação do Supabase, que permite criar login e cadastro de usuários com e-mail, senha ou até redes sociais, tudo de forma simples e segura. Outro recurso interessante é o armazenamento de arquivos (storage), onde é possível guardar imagens, vídeos e documentos diretamente na nuvem. Também vi como usar as funções em tempo real (realtime), que atualizam os dados automaticamente sem precisar recarregar a página. O Supabase é muito útil para quem está começando no back-end, pois elimina a necessidade de criar toda a estrutura do servidor manualmente, permitindo focar na lógica da aplicação e na experiência do usuário. 🧪 Replit O Replit é uma plataforma online de desenvolvimento que permite escrever, executar e compartilhar código diretamente pelo navegador, sem precisar instalar nada no computador. Com o Replit, aprendi a criar projetos em várias linguagens diferentes, como Python, JavaScript, Java, HTML, CSS, PHP e muitas outras. A plataforma oferece um editor de código completo, terminal integrado e a possibilidade de rodar o projeto com apenas um clique. Uma das maiores vantagens do Replit é poder trabalhar de qualquer lugar, até mesmo do celular ou de um computador emprestado. Além disso, é possível colaborar em tempo real com outras pessoas, como se fosse uma sala de aula virtual de programação. Aprendi a usar os recursos de hospedagem do Replit, que permitem publicar um projeto e gerar um link para compartilhar com qualquer pessoa. Isso é ótimo para mostrar trabalhos escolares, criar protótipos e testar ideias rapidamente. Também explorei a parte de banco de dados integrado do Replit e a possibilidade de instalar bibliotecas externas, o que torna a plataforma muito completa para estudos e projetos práticos. 🧠 Considerações Finais Além das linguagens e ferramentas principais que estudei no 3º ano, tive contato com outras tecnologias importantes para o meu crescimento como desenvolvedor.
